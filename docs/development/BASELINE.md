# Usable source baseline

Report development version **`2.0.0b3.dev20261023`** adds explicit comparison
selection and grouped complete intersections, per-figure plotting-data links,
and views of verified completed MotifTrace families and network numerical
imports. These report adapters preserve the original statistical families,
effects and saved source tables. Native completion and source hashes remain
separate from report rendering; the source network's failed plotting lifecycle
is retained when its numerical outputs are independently recovered. Scientific
method versions and the earlier threshold records below remain unchanged.

The preserved application baseline is **`2.0.0b2+baseline.20261022`**. It contains the complete application source, MotifTrace, Katana-Splice-Network and both existing one-click report routes. Its original method versions and parameter inventory remain recorded in `tests/public_baseline/workflow_inventory.json`.

The development version **`2.0.0b3.dev20261022`** implements the approved [every-sample ten-count AS and count-bearing network input policies](../THRESHOLDS.md). Quality, bulk Landscape, DAS, exact cross-comparison and count-bearing CoSplice receive new method versions. The approved module controls preserve the standard 20-event/0.25 defaults and custom YAML settings while adding nullable runtime overrides. Both report routes record actual module parameters when their provenance is available; the interpreted report writes a new run directory. These wrapper/report changes have their own versions. The network module-discovery kernel and all other scientific methods remain unchanged. The original installation, earlier policy documentation and completed research outputs are preserved. New tests compare these specific approved changes against the immutable original inventory.

This is an editable source-checkout baseline. It is not the future minimal headless package, a fully self-contained wheel, a new statistical method or an official nf-core release.

The approved [network annotation policy](../thresholds/network-labels.v1.json)
retains continuous metrics and complete ranks by default. Heuristic member,
stability and hub-candidate labels are opt-in and do not change the fitted
partition. These versioned views retain the original raw scientific cache and
identify threshold-dependent legacy scores separately. Report and dashboard
versions record the actual source policy; historical unknown settings stay
unknown. The raw WGCNA algorithm version is unchanged.

## Publication and portability changes

- Exclude private datasets, generated research results, installed runtimes, workstation configuration and one-off experiment controllers from the public source tree.
- Replace workstation-specific R installation fallbacks with portable configured/environment-based discovery. Scientific models and thresholds are retained.
- Generalize private-study report labels and remove historical sample-count or performance assertions from reusable presentation code. Native compatibility identifiers, file formats and scientific calculations are retained.
- Keep application bookkeeping directories and active lock files out of report inputs, source inventories and ZIP attachments. This prevents report packaging from attempting to read its own active state files; it does not exclude scientific result tables or alter analysis statistics.
- Declare `beautifulsoup4>=4.12,<5` and Requests in the application `next` extra for the existing approved-reader report route and resource-download helper.
- Retain the built browser interface and add original third-party license texts for its locked production dependency closure, including the bundled fonts.

Publication cleanup is performed on the isolated copy. Existing local installations, frozen algorithm releases and completed scientific results are preserved. Further package extraction and pipeline integration continue on the development branch, with algorithm, execution, packaging and presentation changes reviewed separately.
