# Automatic library strandedness

The current `main` source Nextflow workflow accepts `strandedness=auto` for bulk
FASTQ and genome-BAM input, for both single-end and paired-end libraries. Explicit
`forward`, `reverse` and `unstranded` declarations remain supported.

This feature is available in the current `main` source checkout. The published
`v2.0.0-beta.5.dev20261025` assets are unchanged and do not contain it. Run the
`main` source checkout's `pipeline/main.nf`; exporting a workflow from the older
installed wheel does not upgrade it. The new upstream module uses its own
declared RSeQC/gffread environments; the released Katana downstream image remains
usable and unchanged.

## Method and output

FASTQ is aligned through the existing STAR route. Genome-BAM input keeps the
supplied alignments. After the shared BAM audit/sort/index, RSeQC 5.0.3
`infer_experiment.py` measures read orientation against BED12 generated by
gffread 0.12.1 from the matched, unfiltered GTF. Only samples requesting `auto`
run inference. There is no additional alignment or duplicate quantification.

The default sample budget is 200,000 usable alignment records and minimum MAPQ
is 30. These are native RSeQC defaults. Records are sampled in BAM order, not
randomly, and the count is not a count of independent paired fragments.

The direction rule follows [nf-core/rnaseq's classification function](https://github.com/nf-core/rnaseq/blob/3.19.0/subworkflows/nf-core/fastq_qc_trim_filter_setstrandedness/main.nf#L19):
normalize over informative sense and antisense reads; call a direction at
fraction **>=0.8**, or unstranded at absolute difference **<=0.1**. The failed
fraction is retained separately. Ambiguous, zero or malformed evidence fails;
it is never silently labelled unstranded. Thresholds are configurable and must
define nonoverlapping regions. See [parameters](../NEXTFLOW_PARAMETERS.md).

Every selected contrast is rechecked for resolved strand consistency before
Salmon, DEXSeq counts or rMATS preparation can start. Different requested
values such as `auto` and `reverse` may coexist if their actual resolved values
agree. BAM and BAI outputs receive identical resolved metadata.

The native upstream output includes:

```text
upstream/resolve_sample_strandedness/strandedness/
  samplesheet.resolved.csv
  strandedness.audit.json
  strandedness.summary.tsv
upstream/rseqc_inferexperiment/
  SAMPLE.infer_experiment.txt
  SAMPLE.infer_experiment.log
```

The portable bundle retains the requested sheet, per-sample native reports and
logs, method/tool pins and resolution audit under `provenance/strandedness/`.
The bundle's analysis samplesheet contains actual resolved types; its summary
is in `qc/strandedness/strandedness.summary.tsv`. Explicit declarations are
labelled as user-declared, without inventing a measured confidence.

## Validation

[Native Nextflow CI](https://github.com/Taratype0/Katana-splicing-tool/actions/runs/40210590441)
passed at source `1d7bfaf579b0c61fb4b3d40f22f0fb379bb36b2f`, using the production
RSeQC 5.0.3 and gffread 0.12.1 containers and Nextflow 25.10.4.

| Generated alignment case | Result |
| --- | --- |
| Paired-end forward, reverse and unstranded | Correct per-sample calls and downstream metadata. |
| Single-end forward, reverse and unstranded | Correct per-sample calls and downstream metadata. |
| Mixed `auto`/explicit requests with matching actual strand | Accepted; declared values preserved. |
| Explicit-only study | Accepted with zero inference or BED-generation tasks. |
| Ambiguous strand evidence | Resolver failed; zero downstream consumers released. |
| Actual strand conflict within a selected contrast | Resolver failed; zero downstream consumers released. |
| Matching rerun | All eight tasks in the paired-forward case were actually cached. |

The public unit checks also cover missing/duplicate evidence, an empty native
log, zero usable reads, malformed fractions, layout mismatch and invalid
threshold regions. Fourteen upstream unit tests passed, including reference
exclusions. Original Katana source and the approved report controls were
verified unchanged.

These checks qualify the shared post-alignment inference/propagation gate.
They do not claim a new whole-study FASTQ/BAM execution, a new Slurm site, or
reanalysis of Primary culture/public datasets. No such dataset was rerun.
