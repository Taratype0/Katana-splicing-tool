Count windows × coverage windows

Matched declared events, backgrounds and original author consensus models; reads completed results without rerunning quantification or enrichment.

The two methods retain separate P values and BH q values. External evidence is a separate annotation layer: it does not replace thresholds, combine P values, or promote a non-passing result to significance.

Frozen scope

Original rMAPS3 counts use non-overlapping regex matches and the author boundary convention. Coverage is the fraction of bases covered by overlapping motifs and requires a physically complete 50-nt window. Short-exon denominators differ; incomplete windows remain NA rather than zero. Score units differ, so their mean magnitudes are not directly comparable.

Versions, fixed parameters and scope
This matched comparison covers only the author models declared in this bundle. Its recorded hypothesis families do not replace those of a separate extended library. Custom libraries and PWMs without an author counterpart have no count comparison; this is missing evidence, not a negative result.

External evidence for the selected window
External assessment covers only the contrasts and windows explicitly recorded in this bundle; other entries remain not assessed rather than no binding. External q values belong to their own recorded descriptive Fisher/BH family, separate from sequence-method q values and from biological false-positive rates. Tissue and age matching require explicit evidence; a reference CLIP dataset does not establish causality in the current samples.
